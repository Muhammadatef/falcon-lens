# INTEGRATION — ready to connect (not connected)

Falcon Lens has **no** existing integration with Abu Dhabi Police and implies no endorsement. This page describes how a police mobile app or internal agent *could* connect. It will be filled in during Phase 4: REST v1 (OpenAPI in `contracts/openapi.yaml`), the MCP server (streamable HTTP, bearer auth), webhooks (HMAC), the STIX 2.1 export, the data that crosses the boundary, and sovereign mode.
