## Must-checks

1. **Minimum permissions.** I checked the built `dist/manifest.json`. The permission set is minimal, and `extension/PRIVACY.md:43-51` explains each entry.
   - `webNavigation` is needed to see a top-frame navigation before it commits without asking for `tabs`, `<all_urls>` or `webRequest`. The cost is Chrome's "read your browsing history" install warning. That is acceptable because addresses stay on the device unless the prefilter flags them. The e2e test "ordinary and official addresses are not interrupted and nothing is sent" covers this.
   - `storage` holds settings and the session cache. Both areas use `TRUSTED_CONTEXTS` (`src/background.ts:27-28`), so content scripts cannot read the API key.
   - `activeTab` lets the popup read the current tab's URL only after the user clicks it.
   - The only host permission is the API origin `https://localhost/*`. `hostPattern(apiBase)` in `scripts/build.mjs` derives it from the build env.
   - `optional_host_permissions` are `https://*/*`, `http://localhost/*` and `http://127.0.0.1/*`. Nothing is granted at install. `src/options.ts:68-69` requests only the one saved origin.
   - The static `content_scripts` on 5 webmail and chat hosts are an implicit host grant. They are justified and listed in PRIVACY.md:48. The e2e test "not injected outside the listed hosts" covers this.
   - `tabs`, `scripting`, `<all_urls>` and `web_accessible_resources` are absent. The e2e test at `tests/e2e/extension.spec.ts:339-358` asserts this.
2. **No remote code.**
   - The CSP is `default-src 'none'; script-src 'self'; ... object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`, with no `unsafe-*`.
   - The bundle has no eval, `Function` or `importScripts` calls and no remote script URLs. Fonts are bundled from `@fontsource-variable`.
   - The lexicon is generated at build time (`scripts/gen-data.mjs`) and is not committed (`src/generated` is not in `git ls-files`).
3. **Sends only the URL.**
   - The request body is `JSON.stringify({ url })` (`src/background.ts:168`). The fragment is stripped at `:158`.
   - Requests use `credentials: "omit"`, `referrerPolicy: "no-referrer"` and `redirect: "error"` (`:140-143`).
   - The e2e test asserts the body is exactly `{url}` with no `cookie` and no `referer` header (`extension.spec.ts:126-132`).
   - No page content, history or identifiers are read. The content script reads only `a.href` (`src/content.ts:154`).
4. **Attacker strings are rendered as text.**
   - The hover badge sits in a closed shadow root (`src/content.ts:74`) and is built only with `textContent`.
   - The `el()` helper (`src/ui.ts:11-20`) sets `textContent`, and there is no `innerHTML` anywhere. `check-static` enforces this in CI.
   - Server strings are enum-checked and length-capped in `slimVerdict` (`src/shared.ts:114-143`).
   - Hosts are shown defanged.
   - The e2e test injects an XSS payload into a server reason and checks that it is shown as text and runs nothing.
5. **The warning page cannot be framed or linked to.** It is not in `web_accessible_resources`, so web pages cannot load or navigate to it, and the CSP has `frame-ancestors 'none'`. Only the warning page can send `allow` (`src/background.ts:226`, checked against `sender.url`).
6. **Never says "safe".** `grep -i '\bsafe\b|آمن'` only finds comments that state the rule. Lint enforces the rule, and the e2e test at `extension.spec.ts:297` checks the rendered text.
7. **`no_warning_signs` is shown only for a final verdict, with caution.**
   - `src/warning.ts:48-52` and `src/content.ts:173` both require `final === true` before showing it.
   - The caution list is rendered at `warning.ts:114` and the badge caution at `content.ts:176`.
   - Only final verdicts are cached (`background.ts:181`).
   - This matches CONTRACTS.md invariant 3 (`actions.caution` exists in the schema).
8. **"Continue anyway" is scoped and time-limited.** The choice is per host with `ALLOW_TTL_MS = 10 min` (`src/shared.ts:12`). It lives in `chrome.storage.session` and is checked against `Date.now()` in `background.ts:82`. Only the warning page can record it, and "Go back" is the primary action.
9. **Brand tokens come from `data/brands.yaml` at build.**
   - `gen-data.mjs` runs before build, test and lint and fails if `falcon_demo_bank` is missing.
   - The icons are an original lens mark (I viewed `static/icons/icon-128.png`) with no real-brand imitation.
   - `tokens.css` is the project's own Night theme.
10. **Screenshots.**
    - I viewed `warning-dangerous-ar-390.png`, `hover-badge-webmail-ar.png` and `popup-no-warning-signs-en.png`. All use Falcon Demo Bank `.test` hosts, shown defanged, and show the DEMO DATA badge (بيانات تجريبية). The webmail mock is labelled "TEST FIXTURE, not a real site".

11. **vitest 5.1.1 deviation.** It is acceptable. It is logged in DECISIONS.md with the reason (advisories in 3.2.x), `pnpm audit` is clean in CI, and the version is pinned in the lockfile.
12. **Contracts.** `contracts/` is unchanged. ## On-device prefilter false-positive risk

- **Method.** I bundled `src/prefilter.ts` and the generated lexicon with esbuild into a scratch Node script. For each row of `evals/datasets/legit_urls.csv` it refangs `hxxp`→`http` and `[.]`→`.`, then calls `prefilter(url, lex, [])`. A row counts as an interruption when it returns `level === "warn"`.

- **Limits of this measurement.** This is a reviewer run, not an `evals/results/` artifact, so it must not be quoted as a metric in any doc. The dataset is UAE-centric and has no free-host pages and no foreign brand subsidiaries.
- **Probe results.** I ran synthetic probe hosts through the prefilter. None are in any committed file, and they are defanged here. These all **interrupt**:
  - `etisalat[.]com[.]eg` and `etisalat[.]af` (brand_in_host)
  - `www[.]mashreqbank[.]com[.]eg` (brand_in_host)

  - `salikh[.]org`: brand_in_host, because the 5-character token `salik` matches as a substring

  This confirms the open risk the builder stated in the PR (foreign subsidiaries, no PSL). It does not show up in the current legit set.
