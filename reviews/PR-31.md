**B3. check_numbers.py: once an artifact exists, digits inside its strings make any bare integer "traceable".**
- `Traceable._text()` adds every `\d+` run from every key and every string value (git SHA, timestamps, dataset hash) to `self.loose`.
- `has_number()` accepts any non-percent number found in `loose`.
- With an artifact holding `git_sha: "7e52a88"`, `created_at: "2026-11-22T18:04:22Z"` and `dataset_hash: "sha256:98ab31c0"`, all of these pass:
  - `Recall is 98 percent.`
  - `We caught 98 scams.`
  - `22 campaigns blocked`
  - `52 incidents opened`
  - `88 lookalike domains`
- With no artifact, all five are caught. A hex hash contains dozens of 1 to 3 digit runs, so this hole is wide.
- Fix:
  - Drop `loose` matching entirely.
  - Trace hex words and ids only as whole tokens equal to a full artifact string value. `has_hex` already works this way.
  - Add a regression test using exactly these strings.

**B4. Percentage bypasses: `percent` is only `%` or `٪`.**

These pass (artifact present or absent unless noted):

| Input | Why it passes |
|---|---|
| `98 percent` and `98 per cent` | With an artifact, these pass through `loose` (B3). Without one, the word is still not treated as a percentage, so a future ALLOWED_CONTEXTS match would exempt it |
| `ninety-eight percent` | number words are not checked at all |
| `و٩٨٪` and `بنسبة٩٨٪` | the Arabic letter is attached. `_NUMBER`'s lookbehind `(?<![\w.])` is Unicode-aware, so Arabic letters count as `\w` and the number is never matched. The Arabic conjunction «و» and preposition «بـ» attach to the next word, so this is the natural way to write it |
| `98％` | fullwidth percent sign |
| `F1 .98` | leading dot |
| `recall ⁹⁸` | superscript digits |
| README `` `98%` `` | inline code is stripped before scanning |

Fix:
- Use an ASCII-only lookbehind, e.g. `(?<![A-Za-z_.])`, so the identifier rule still covers `T0` / `H1`.
- Treat `%`, `٪`, `％`, `percent`, `per cent`, `بالمئة`, `في المئة` and `بالمائة` as percent markers.
- Match `\.\d+`.
- Normalise with NFKC before scanning.
- Flag English and Arabic number words next to a percent marker or metric word (recall, precision, accuracy, دقة, كشف, نسبة).
- Do not strip inline code spans that contain `%`.
- Add tests for each case.
