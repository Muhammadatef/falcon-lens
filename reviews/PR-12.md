Under union, two concurrent edits to the same card line merge silently and keep both versions (shown above). Mitigation, no change needed now: after any local merge that touches `TASKS.md`, I check for duplicate card fields. Prefer status changes as appended lines (`- 2026-11-22 · T-0xx → DONE`) over edits.
2. **INFO: scope of the merge driver.** Union applies to local `git merge`/`rebase`. GitHub's own conflict detection and the web conflict editor may not honour custom merge attributes, so a GitHub PR can still show a conflict on these files. If that happens, merge locally.
