# Design, layout, animation, architecture and docs audit — 24 Nov 2026, 19:00 GST

Auditor: Fable. Scope: the live site `https://falconlens.app` and the local production build of `origin/main` at `5a9e44f`, plus `README.md`, `docs/ARCHITECTURE.md`, `docs/assets/*.svg` and the interactive architecture.

## How it was measured

- **Live matrix.** 15 pages x Arabic and English x 390 px and 1440 px x dark and light = 120 full-page screenshots with Playwright (Chromium, reduced motion). For each page: HTTP status, horizontal overflow, `h1` count, document title, `dir`/`lang`, a search for "safe" / «آمن», console errors, and axe (all rules) on 90 of the 120 combinations.
- **Pages.** `/`, `/voice`, `/agents`, `/campaigns`, `/history`, `/checks/vd_01M86YX0KB1FCKKJ6QF4K519KJ`, `/incidents/inc_01M86XTG821AQF04EX8H0RVQMN`, `/results`, `/authorities`, `/privacy`, `/docs`, `/docs/agents`, `/docs/cascade`, `/docs/integration`, `/ops` (no key).
- **Performance.** LCP and CLS from `PerformanceObserver` in Playwright at 390 px (Pixel 7 profile) on the live site, one run per page. **Lighthouse was not run**; treat the performance figures as a single-run indication, not a Lighthouse score.
- **Screenshots.** The 120 live shots and the after-shots were written to the session scratch folder and are not kept. Three are committed as evidence in `reviews/assets/design-20261124/`. To regenerate the after-shots: `SHOTS=1 SHOTS_DIR=/abs/dir pnpm exec playwright test --project=shots tests/shots/fable-polish.shots.ts`.

## Findings

### P0

**P0-1. The architecture was not presented as the owner asked: three stacked layers (owner request, relayed by L1 at 18:40).**
Fixed. New `ArchLayers` component on `/agents`, `/docs` and `/docs/agents`; new `docs/assets/architecture.svg`; new README section. Details under "What was fixed".

**P0-2. Internal references were visible to judges: "ADR-001" badges, "This page restates docs/SCORING.md", raw file paths in the diagram panel (owner request, relayed by L1 at 18:50).**
Evidence: `grep -n "ADR" web/lib/*.ts` found them in `arch-content.ts`, `docs-content.ts` and `i18n-arch.ts`; the diagram panel listed paths such as `packages/falcon_core/src/falcon_core/agent/investigator.py`. Fixed.

### P1

**P1-1. `/voice`: the three "How do I use it?" steps had no numbers.**
Evidence: `reviews/assets/design-20261124/before-voice-en-light-1440.png`. Cause: `web/app/globals.css:47` resets `ol { list-style: none }` and `.voice-how ol` never restored it. Fixed.

**P1-2. `/incidents/[id]`, English, 390 px: the page scrolls sideways.**
Evidence: `scrollWidth` 408 against 390; the widest element is the pill "Template used instead of model output" (`white-space: nowrap`) inside a grid track with no `minmax(0, 1fr)`. Fixed.

**P1-3. Voice documentation was stale: it said no model is involved in intent.**
Evidence: `web/lib/voice-doc.ts` ("Fixed rules, not a model, decide what you asked"), `web/lib/i18n-arch.ts` ("No model is involved"), `README.md` and the old SVG ("fixed rules, no model"). The code has a semantic fallback with a local embedding model (`packages/falcon_core/src/falcon_core/voice/faq_semantic.py`), and `docs/PRIVACY.md` already says so. Fixed in all five places, Arabic and English.

**P1-4. Sovereign-mode statements were stale or too strong.**
- `README.md` (three places), `docs/ARCHITECTURE.md` and `docs/INTEGRATION.md` said the sovereign proof run was "pending", while four artifacts are published in `evals/results/published/sovereign/`. Fixed, with the honest result: one run recorded as `passed`, three as `failed` (the seven scenarios passed in all four; the Sentinel summary fell back to the template in three).
- `docs/ARCHITECTURE.md` said the voice clips are "Kokoro and macOS `say`"; the Arabic clips are Amazon Polly Zayd. Fixed.
- `web/lib/docs-content.ts` and `web/lib/page-content.ts` said "no content leaves the machine" in sovereign mode. `docs/EVALS.md` says explicitly this is not claimed. Changed to "no message or page content is sent to a cloud model", both languages.
- The route selector merged in #130 was missing from `README.md` and `docs/ARCHITECTURE.md`. Added.

**P1-5. The verdict label was written «خطير» in one place.**
Evidence: `web/lib/public-history.ts` rule R4 line. The agreed label is «خطِر». Fixed.

**P1-6. `/checks/[id]` and `/incidents/[id]` had one fixed bilingual title in both languages.**
Evidence: title "مسار الفحص | عدسة الصقر · Check trace | Falcon Lens" on the English page. Every other page uses `pageMetadata(lang, ...)`. Fixed.

**P1-7. Two axe moderate findings.** `heading-order` on `/results` (`.live-fp > h3` directly under the `h1`) and `landmark-unique` on `/docs/integration` (a section and its table wrapper were both regions with the same name). Fixed.

**P1-8. NOT FIXED, for L1: the Sentinel trace shows the model id "stub" for real model calls.**
Evidence: live `/incidents/inc_01M86XTG821AQF04EX8H0RVQMN` shows "cloud model · stub" with 1,428 input tokens and a 7.6 s step. `services/sentinel/src/falcon_sentinel/graph.py:237` reads `getattr(deps.llm, "model", "stub")`, so a client without a `model` attribute is recorded as "stub". A judge reading the trace will think a stub answered. This is product code, outside this PR's scope. The cause is `unverified` beyond that line.

**P1-9. NOT FIXED, for L1: a Falcon Demo Bank campaign is shown as live data.**
Evidence: live `/api/public/campaigns` returns `cmp_01M8411ADCKWSZYFGA0MVX4S4Q`, 32 linked checks, title "impersonating Falcon Demo Bank", `source: "live"`, so `/campaigns` shows it with the "live" pill and no "test data" label. The brand is invented, so the card needs a fixture label. An existing e2e test (`web/tests/e2e/boards.spec.ts:54`) asserts that a live Falcon Demo Bank campaign carries no source badge, so changing it is a product decision. Options: mark the source at ingestion, or label any campaign on the invented brand in `web/lib/public-campaigns.ts`.

**P1-10. NOT FIXED, for L1: layout shift on the live boards.**
CLS 0.80 on `/campaigns`, 1.03 on `/history`, 0.52 on `/incidents/[id]` (single run, 390 px). The lists load on the client and push the footer down. A reserved minimum height on the board container would remove most of it; not attempted so close to the freeze because it touches every board.

**P1-11. NOT FIXED, for L1: `pages[.]dev` appears as a campaign indicator.**
Evidence: the same live incident lists `pages[.]dev` (a shared hosting suffix) as one of three "domains with the same page fingerprint", and `block_indicator` ran automatically twice. Correlating on a shared-hosting registrable domain will group unrelated sites. Detection logic, outside this PR.

### P2 (listed, not fixed)

1. `/voice` and Home show a "Preview" badge on the voice assistant; `/agents` shows "working now" on the same feature. Pick one.
2. `/agents` voice heading is bilingual inside a single-language page ("المساعد الصوتي | Voice assistant").

4. `/history` at 390 px is 14,591 px tall (50 cards). Consider 20 per page on phones.
5. `/checks/[id]` at 1440 px: the details table uses half of the card; the row label "ID" is English on the Arabic page.
6. `/incidents/[id]`: "Budget: 3 · 5061 · 9859 ms" has unlabeled numbers.
7. English trace title is "Sentinel · درع: agent run"; elsewhere the pattern is "Dir', the Sentinel".
8. The interactive diagram in the plain view shows "assess (التقدير)" and "propose (الاقتراح)", English first on the Arabic page.
9. `/ops` without a key fires one request that returns 401 and logs a console error.
10. `web/lib/i18n.ts` "Local only: people's text never leaves the machine" (`agents.route.local`): the sandbox still visits the checked link. Same family as P1-4; left because it is the label of the route selector merged today.
11. Cloud-mode privacy line says only "lookups that carry domain names" leave the machine; the sandbox visit carries the full link. Wording for the owner.
12. `docs/assets/features.svg` has no voice entry.
13. `reduced motion` is handled by a list of selectors in `globals.css`, not by one global rule. The new e2e test guards it.
14. Lighthouse budgets were not run in this pass.
