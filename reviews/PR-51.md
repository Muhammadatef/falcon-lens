## Blocking findings

1. **The AI Investigator, extractor and responder are presented as live. They are not wired on main.**
   - Where: `web/lib/page-content.ts:73-95,112-134` ("Two AI agents work inside the system… [Investigator] Called only when the fixed rules cannot settle a case"); `web/lib/arch-content.ts:69-79,154-163` (T2 extractor, T3 loop, RESPONDER shown as steps of the running flow); `web/public/images/ai-agents.svg` and `how-it-works.svg` ("Only unclear cases get a closer look by AI").
   - What main actually does: `packages/falcon_core/src/falcon_core/cascade/engine.py:499-501` says `# T3 investigator is not built yet … record the escalation only` and outputs `"uncertain band, T3 escalation recorded (investigator not enabled)"`. `grep -E 'Extractor|Investigator|Responder' services/worker/src services/api/src` finds nothing, so the worker wires no LLM. That wiring is open PR #47.
   - Fix: add a visible build-status line to each agent and each layer. The Sentinel is running (true: `services/sentinel/src/falcon_sentinel/graph.py`, and the Sentinel claims checked out: budgets 8/20k/60 s, RetryPolicy max_attempts=3, AsyncPostgresSaver, `interrupt()`, MAX_BLOCKS). The Investigator, extractor and responder are "built and unit-tested; not yet connected to the live check (in progress)". The ai-agents.svg footer itself says "THE DESIGN. BUILD STATUS IS IN THE README.", but the website gives no build status. While doing this, soften the absolute "A web page cannot give it orders" / "لا يستطيع محتوى صفحة ويب أن يوجّه إليه أوامر" (`page-content.ts:82,121`; `arch-content.ts:65,150`) to "designed so that…". `injection_attack_success_rate` is listed as **not evaluated** in the same site's Results page.

2. **Messages, emails and images are presented as checked. On main they return a degraded verdict.**
   - Where: `page-content.ts:65,104` (step 1: "Paste a link, message, email or image"), `web/lib/meta.ts:5-6` (site description: "Check suspicious links, messages and emails … clear evidence-backed verdict in seconds"), and how-it-works.svg ("Link / Message / Email / Picture or QR").
   - What main actually does: `services/worker/src/falcon_worker/consumer.py:302-303,360-366` answers `input_type_not_supported_yet:<type>` for every non-URL input.
   - Fix: say link checks are live, and messages, emails and pictures are in progress, matching README lines 51 and 155.

3. **The Results scope does not say that the measured model is not the one the running service uses.**
   - Where: `web/app/results/page.tsx:45,80` say the evaluation "measures the statistical address model (T1) together with the deterministic arbiter".
   - What main actually does: the fitted `t1_hgb` model is never loaded by the running cascade. Nothing outside the evals calls `scoring/t1_model.py`; loading it is item 4 of PR #47. A judge will read these figures as product performance.
   - Fix:
     - Add "Offline measurement. The measured T1 model is not yet loaded by the running service."
     - Render the artifact's own `scope` string and `git_sha` instead of only a fixed paraphrase. The paraphrase is hard-coded and will go stale silently when a new artifact is published.
   - Note for L1 (not this PR's fault): the published artifact's `git_sha` is `ac36c6a…-dirty`.

4. **Privacy statements that no code implements.**
   - (a) `page-content.ts:219,240` says "Verdicts are kept for 30 days, then aggregated". No retention or aggregation job exists. `grep -iE 'retention|DELETE FROM|purge|aggregate'` over services/ and packages/ finds only the per-verdict evidence rewrite at `services/worker/src/falcon_worker/store.py:107`, Sentinel incident rewrites, and Loki's 168 h log retention. Either state it as a policy target that is not yet automated, or remove it.
   - (b) `page-content.ts:214,235` says "Before logging … we redact". `falcon_core/telemetry/logging.py` `sanitize()` only escapes control characters and truncates. PII redaction happens only in `llm/router.py:181` (before model calls). Reword to "before any cloud model call".
   - (c) Footer on every page: `web/lib/i18n.ts:226,463` says "We do not keep what you paste unless you choose to report it." The worker stores the verdict doc, including the defanged link and the evidence (`store.py:102`). Reword, for example: "Links are kept only in defanged form with their verdict. Message text is not kept unless you report it."
   - (a) and (b) are copied from `docs/PRIVACY.md`. L1 should correct that doc too.
